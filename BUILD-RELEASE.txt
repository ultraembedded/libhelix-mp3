MintAMP 2.0 development build recipe (PR #521)
=============================================

Build from the 2.0 branch (or a working branch based on it). These commands create
local development drawers. They do not publish, tag, merge or update 1.4.0.
Run from the repository root with the Amiga cross-compiler tools on PATH.

Run the automated checks first:

make -f Makefile.amiga launcher-test interface-prefs-test skin-format-test skin-controls-test \
  skin-eq-decode-test skin-performance-test skin-sprite-test integer-stats-test \
  gadtools-radio-layout-test playlist-format-test radio-metadata-test \
  radio-oggflac-test radio-favourites-test display-text-test freeall-heads-test \
  aac-mulshift60-ref-test ogg-mulshift60-ref-test wma-mulshift-ref-test \
  flac-lpc-ref-test mpeg25-decode-test fdct32-lowbands-test \
  polyphase-stride3-reduced-test

68030 drawer (68030/68040 and compatible accelerated systems)
-----------------------------------------------------------

make -f Makefile.amiga clean
make -f Makefile.amiga release CPU=30 RADIO=1 SSL=1 SSLCERTS=1 \
  RELEASE_NAME=MintAMP-2.0-dev-68030

68060 drawer (including FPU-less 68060)
------------------------------------

make -f Makefile.amiga clean
make -f Makefile.amiga release CPU=60 \
  ASM60_GROUPS="lowrate060 huffman midside planars8" \
  RADIO=1 SSL=1 SSLCERTS=1 RELEASE_NAME=MintAMP-2.0-dev-68060

Always clean when changing CPU, compiler or optimisation options. The second
clean leaves the first packaged drawer intact. Do not mix decoder modules
between CPU drawers. release-clean removes all packaged drawers; use only at
the start if you intend to discard previous local packages.

Each drawer includes MintAMP-Launch and its icon, the four existing frontends
and their legacy icons, amiga_mp3dec.fastexp, CPU-matched AAC/FLAC/Ogg/WMA/WAV/IFF
modules, Skins/MintAMP-mintleaf.wsz, ArtCache and documentation. Start with
MintAMP-Launch: the mint-leaf skin opens first (ReAction framework). Right-click
the skin, MintAMP > Classic interface, to flip the running player to the
classic window; untick Project > Classic interface there to flip back. Use
Interface preferences in any frontend (or MintAMP-Launch --prefs) for the
next-launch framework and appearance.

RADIO=1 enables radio; SSL=1 enables AmiSSL; SSLCERTS=1 enables certificate
and hostname verification. AmiSSL runtime and root certificates must be
installed. Keep task-safe allocation and exact-binary free-all validation.
The established 68030 assembly path and the explicit 68060 assembly group
are unchanged. Never inherit the complete 68030 bundle in a 68060 build.

EXTRA_CFLAGS=-msoft-float is available for additional application compilation
checks. The application integer-source guard does not prove that all external
libraries are FPU-free. Test the installed OS libraries and CPU-matched decoder
modules on the actual FPU-less board. See docs/mintamp-2.0-acceptance.md.

GitHub Actions compiles both CPUs and uploads development drawers. Host CPU
measurements and successful cross-compilation do not establish Amiga playback
headroom. Real audio.device/Intuition tests are required before a 2.0 release.
